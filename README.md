# SkripsiGame (Game Edukasi Anak SLB)

Yah ini adalah projek skripsi saya sebagai lulusan S1 Teknik Informatika, kenapa saya mengambil tema game untuk skripsi saya?
ya karena saya ingin cepat lulus dan pembuatan game edukasi ini adalah salah satu cara yang mudah untuk mendapatkan data dan hasil yang cepat. Dengan penerapan yang mudah dan sesuai dengan kurikulum dari subjek yang akan kita teliti, saya berhasil lulus tepat waktu.

Judul Game ini adalah "Pengenalan Bangun Datar dan Warna" untuk anak kelas 3 SD SLB, saya melakukan penelitian ini di SLB YPSLB Kerten.

Dan ini adalah Dokumentasi untuk diri saya sendiri.
